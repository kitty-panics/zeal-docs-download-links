# Zeal Docs Download Links

Zeal 中所有文档的下载链接。

## 使用

在 Zeal 内建下载器下载缓慢、下载失败时，可以尝试手动从离自己最近的服务器下载文档，
并解压至文档存放目录。

文档默认存放位置: `~/.local/share/Zeal/Zeal/docsets`。

## 下载

文档分为官方维护和第三方维护两类。两者都提供了多个位置的下载服务器。
